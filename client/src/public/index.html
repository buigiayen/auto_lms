TỰ ĐỘNG HÓA 04

Worker & khóa đăng ký

Tạo khóa bootstrap an toàn để Worker được phép tự đăng ký các lane với Backend.

RegistrationApiKey

Khóa ngẫu nhiên 256-bit, đáp ứng yêu cầu tối thiểu 32 ký tự.

Lưu ý: Khóa được tạo ngay trong trình duyệt, không gửi tới Backend và không được lưu sau khi đóng hoặc tải lại trang. Hãy sao chép và cấu hình cùng một giá trị ở Backend lẫn Worker.

Nếu mất khóa, hãy tạo khóa mới và cập nhật ở cả Backend lẫn Worker.

Cách sử dụng

  1. Trong terminal chạy Backend, đặt biến môi trường WORKER_REGISTRATION_KEY rồi khởi động lại Client API:
    export WORKER_REGISTRATION_KEY="<khóa vừa sao chép>"
npm start
  2. Ở Worker V2, đặt Worker:RegistrationApiKey bằng đúng khóa đó. Ví dụ dùng User Secrets:
    dotnet user-secrets set "Worker:RegistrationApiKey" "<khóa vừa sao chép>" --project LotusLMS.Worker.V2
  3. Khởi động Worker. Worker sẽ tự đăng ký từng lane; Backend tạo và cấp API key riêng cho từng lane.

Không gửi khóa qua chat, không lưu vào Git hoặc appsettings. Nếu Backend đã chạy, cần khởi động lại sau khi thay đổi biến môi trường.
